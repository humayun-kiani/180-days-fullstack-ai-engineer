What TaskMind Does

🤖

AI Prioritization

Claude analyzes your task title and description, suggests a priority level with reasoning. Works without an API key using a smart keyword fallback.

📝

AI Task Expansion

Type "Add dark mode" — Claude writes a full engineering description with context, approach, and considerations.

🔀

Task Breakdown

"Build checkout page" becomes 5 subtasks with time estimates. Plan sprints in seconds instead of hours.

⚡

Real-time Sync

WebSocket keeps all your tabs updated instantly. Create a task on mobile, see it on desktop without refreshing.

🔍

Full-text Search

⌘K to open search. Filter, sort, paginate. Keyboard navigation throughout. WCAG AA accessible.

📊

Smart Statistics

Completion rate, velocity, health score, overdue count — computed in a single SQL aggregation query.

📤

Export

Download your tasks as CSV or JSON in one click. Streaming response — works with any dataset size.

📱

PWA + Mobile

Install to home screen. Swipe left to delete, right to complete. WCAG AA: full keyboard + screen reader support.
